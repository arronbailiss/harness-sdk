Named strategy presets are shorthand for preconfigured `Offload` strategies.

<Tabs>
<Tab label="Python">

The `ContextManager` strategy API is exported from
`strands.experimental.context_manager` and may change in future versions.

Pass preset names as strings in the `strategies` array.

</Tab>
<Tab label="TypeScript">

The strategy API is stable. Pass preset names as strings in the `strategies`
array.

</Tab>
<Tab label="Rust">

Pass `StrategyPresetName` variants in the `strategies` array.

</Tab>
</Tabs>

Preset expansions are internal defaults and may change between releases as tuning improves. The preset _name_ is the stable contract. Use raw `Offload.*` strategies when you need a pinned configuration.

## Available presets

<Tabs>
<Tab label="Python">

| Preset                  | Name                        | Description                                                                                               |
| ----------------------- | --------------------------- | --------------------------------------------------------------------------------------------------------- |
| Proactive summarization | `"proactive_summarization"` | Summarizes the oldest 30% of messages when the context window reaches 70% capacity.                       |
| Large tool offloading   | `"large_tool_offloading"`   | Truncates individual tool results over 2,500 tokens to a 1,000-token preview, eagerly on message arrival. |
| Overflow protection     | `"overflow_protection"`     | Truncates the oldest messages when the context window is full, keeping the 4 most recent.                 |
| Stale tool cleanup      | `"stale_tool_cleanup"`      | Drops tool results more than 5 messages old.                                                              |

</Tab>
<Tab label="TypeScript">

| Preset                  | Name                       | Description                                                                                               |
| ----------------------- | -------------------------- | --------------------------------------------------------------------------------------------------------- |

| Overflow protection     | `"overflowProtection"`     | Drops the oldest messages when the context window is full, keeping the 4 most recent.                     |
| Stale tool cleanup      | `"staleToolCleanup"`       | Drops tool results more than 5 messages old.                                                              |
| Deferred tool loading   | `"deferredToolLoading"`    | Defers tool schemas.                                                                                      |

</Tab>
<Tab label="Rust">

- **Proactive summarization**:
  `StrategyPresetName::ProactiveSummarization` summarizes the oldest 30% of
  messages at 70% utilization.
- **Large tool offloading**:
  `StrategyPresetName::LargeToolOffloading` truncates tool results over 2,500
  tokens.
- **Overflow protection**: `StrategyPresetName::OverflowProtection` drops the
  oldest messages at full utilization.
- **Stale tool cleanup**: `StrategyPresetName::StaleToolCleanup` drops tool
  results outside the newest five.
- **Deferred tool loading**: `StrategyPresetName::DeferredToolLoading` defers
  tool schemas until the model loads them.

</Tab>
</Tabs>

On Claude models that preserve thinking, large tool offloading keeps thinking blocks valid, and so does proactive summarization when it runs server-side. Overflow protection and stale tool cleanup drop them. See [Models that preserve thinking](./custom-strategies#models-that-preserve-thinking).

## Mixing presets and custom strategies

Combine named presets with raw `Offload` strategies in the same array. Order matters: strategies run as a pipeline, and each sees the output of the previous.

<Tabs>
<Tab label="Python">

```python
from strands import Agent
from strands.experimental.context_manager import Offload

agent = Agent(
    context_manager={
        "strategies": [
            "large_tool_offloading",
            Offload.summarize("*").when(
                utilization=0.9,
                preserve_recent=2,
            ),
        ],
    },
)
```
