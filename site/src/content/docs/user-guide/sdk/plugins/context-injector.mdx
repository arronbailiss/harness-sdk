The `ContextInjector` plugin folds real-time text into the latest user message
before a model call. It stores the text as an injected block in the
conversation, while model adapters limit how that block is replayed. Use it for
the current time, a sandbox descriptor, environment facts, or a retrieval
lookup.

## How It Works

A `ContextInjector` has two parts. The callback function decides **what** text
to fold into the next model call's input. The trigger decides **when** the
callback is called. The injected block stays attached to the user message.
Models with temporary-message support receive it as a system message scoped
until the next user message. Other models receive injected blocks from only the
latest user message as text.

This is the same injection mechanism that powers [memory context injection](../memory/managing-memory#context-injection). `ContextInjector` is the generic surface for any consumer.

## Getting Started

Pass a `ContextInjector` to your agent's `plugins` list with a callback that renders the text to inject. By default it injects only on a fresh user turn, the common case for chat agents:

<Tabs>
<Tab label="Python">

```python
from datetime import datetime, timezone

from strands import Agent
from strands.vended_plugins.context_injector import ContextInjector

agent = Agent(
    plugins=[
        ContextInjector(lambda context: f"<now>{datetime.now(timezone.utc).isoformat()}</now>"),
    ],
)
```

## When to Inject

The trigger controls when the callback runs:

- <Syntax py="'userTurn'" ts="'userTurn'" rs="InjectionTrigger::UserTurn" />
  (the default) injects only when the latest message is a fresh user ask, a user
  message carrying no tool result. This is the common case for chat agents.
- <Syntax py="'everyTurn'" ts="'everyTurn'" rs="InjectionTrigger::EveryTurn" />
  injects before every model call, including mid-task tool-result turns. Use it
  for autonomous agents that should consult the injected context at each step.

<Tabs>
<Tab label="Python">

```python
from datetime import datetime, timezone

from strands.vended_plugins.context_injector import ContextInjector

clock = ContextInjector(
    lambda context: f"<now>{datetime.now(timezone.utc).isoformat()}</now>",
    name="clock",
    trigger="everyTurn",  # inject before every model call, not just fresh user asks
)
```

For finer control, pass a predicate: a function that receives the injection
context and returns whether to inject this call. The context carries the current
messages, durable state shared across calls via
<Syntax py="context.state" ts="context.appState" rs="context.app_state" />,
and the agent. A predicate that fails is ignored, so the model call proceeds:

<Tabs>
<Tab label="Python">

```python
from strands.vended_plugins.context_injector import ContextInjector

injector = ContextInjector(
    lambda context: f"<context>{len(context.messages)} turns so far</context>",
    # Inject only when a tool stashed a flag in agent state last turn.
    trigger=lambda context: context.state.get("recall_enabled") is True,
)
```

## Configuration

- <Syntax py="render_content" ts="renderContent" rs="render_content" />:
  required callback. Return
  <Syntax
    py="None or an empty string"
    ts="undefined or an empty string"
    rs="None or a blank string"
  /> to skip.
- `trigger`: user turn (default), every turn, or a predicate over the injection
  context.
- `name`: plugin name for logging and duplicate detection. It defaults to
  `'strands:context-injector'`. Use a distinct name for each injector.

:::caution[Injected text reaches the model verbatim]
The rendered text is a prompt-injection surface. If it interpolates
attacker-influenced data, escape it before returning. If the callback fails,
injection is skipped and the model call proceeds.
:::
