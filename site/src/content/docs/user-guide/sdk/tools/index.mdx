Give your agent the ability to do things beyond generating text: call an API,
read a file, run code, or query a database. You pass tools to an agent, and the
agent decides when to call them based on the request. Strands works with custom,
vended, community, and MCP tools.

:::caution[Tool Security]
All tools, whether custom, community-provided, or included in the Strands tools package, execute code on behalf of your agent with the permissions of the host process. Under the shared responsibility model, you should audit each tool's behavior (file access patterns, network calls, shell execution) and ensure it is appropriate for your deployment environment and threat model. See [Responsible AI](../safety-security/responsible-ai.md) for more details.
:::

## A running agent with a tool

The smallest useful setup is an agent with a single tool it can decide to call. Define the tool, pass it to the agent, and invoke:

<Tabs>
<Tab label="Python">

```python
from strands import Agent, tool


@tool
def get_weather(city: str) -> str:
    """Get the current weather for a city."""
    return f"It's sunny in {city}."


agent = Agent(tools=[get_weather])
agent("What's the weather in Seattle?")
```

The agent reads the tool's description and decides when to call it. From here you add the tools your application needs and control how they run.

Rust custom tools work with the default crate features. To connect MCP tools,
enable the optional `mcp` feature.

## Where to go next

New to tools? Start with [Attach and invoke tools](using-tools.md) to see how tools load onto an agent and the two ways to call them, then [Create custom tools](custom-tools.md) to build your own.

Bringing in tools that already exist? Reach for [vended tools](vended-tools/index.md) or connect an [MCP server](mcp-tools.md). Still on the deprecated community tools package? See [Migrate from the community tools package](../../migrate/strands-agents-tools.md). When a model returns several tool calls at once, [tool executors](executors.md) decide whether they run concurrently or in order.
