This is the lookup layer for the
<Syntax py="create_harness" ts="createHarness" rs="create_harness" />
factory. Every argument is optional. For practical examples, follow the links into the
configure and tools guides.

## Options

<Tabs>
  <Tab label="Python">
    | Option | Default | Purpose |
    |---|---|---|
    | `model` | `bedrock/global.anthropic.claude-opus-5-5` | A `provider/name` string, a bare Amazon Bedrock id, a model router, or a model instance. See [choose a model](../../configure/model/). |
    | `effort` | `"auto"` | Reasoning effort. Ignored for a model instance or router. |
    | `instructions` | none | A domain block appended after the harness contract. Ignored when a full system prompt is passed. |
    | `tools` | none | Consumer tools added alongside the built-ins. See [add tools](../../configure/tools-and-instructions/). |
    | `plugins` | none | Consumer SDK plugins added alongside the built-in plugins. |
    | `mcp_servers` | none | MCP servers to connect: a JSON file path or a mapping. See [MCP servers](../../configure/mcp-servers/). |
    | `builtin_tools` | `shell`, `read`, `write`, `edit`, `web_fetch`, `web_search`, `programmatic_tool_caller`, `subagent` | Built-in tools to enable, or `[]` for none. |
    | `builtin_tools={"web_fetch": {"model": ...}}` | provider default | The summarizer model `web_fetch` runs on. See [web access](../../tools/web-access/). |
    | `caching` | `"auto"` (on) | Prompt caching where the provider supports it; off disables what the harness configures. |
    | `context_manager` | `"auto"` | `"auto"`, `"agentic"`, or off. Enables context management and offloading. |
    | `session={"id": ...}` | generated id | Persists and resumes a conversation by id. |
    | `session={"dir": ...}` | `./.agent/sessions` | Where session state and offloaded artifacts live. |
    | `skills` | `./.agent/skills` when present | Directory or list scanned for Agent Skills; off disables loading. |
    | `builtin_plugins` | `["environment"]` | Built-in feature plugins to enable (`todos` is opt-in), or `[]` for none. |
    | `memory` | on | File-based long-term memory; off disables it. |
    | `memory={"dir": ...}` | `./.agent/memory` | Where the default memory store writes files. |
    | `memory={"stores": [...]}` | none | Replaces the memory store while keeping the harness policy. |
    | `interventions` | none | Gates tool calls behind approval or a policy. See [interventions](../../configure/interventions/). |
    | `background_tasks` | agentic `*`; `subagent` always | Background-task policy. See [background tasks](../../configure/background-tasks/). |

## Value notes

<Tabs>
  <Tab label="Python">
    - `effort` accepts `"auto"`, `"off"`, and explicit provider levels. A level
      the resolved provider rejects fails at construction.
    - `caching` accepts `"auto"` or `True` to enable, and `False` or `None` to
      disable. Automatic provider caching is unaffected.
    - `context_manager` accepts `"auto"`, `"agentic"`, `False`, or `None`.
      Disabling it also disables context offloading.
    - `memory` accepts `True`, `False`, or `None`. An explicit `memory_manager`
      takes precedence.
    - `builtin_tools` and `builtin_plugins` accept lists of names. Unknown names
      fail during construction and list the valid names.
  </Tab>
  <Tab label="TypeScript">
    - `effort` accepts `'auto'`, `'off'`, and explicit provider levels. A level
      the resolved provider rejects fails at construction.
    - `caching` accepts `'auto'` or `true` to enable, and `false` or `null` to
      disable. Automatic provider caching is unaffected.
    - `contextManager` accepts `'auto'`, `'agentic'`, `false`, or `null`.
      Disabling it also disables context offloading.
    - `memory` accepts `true`, `false`, or `null`. An explicit `memoryManager`
      takes precedence.
    - `builtinTools` and `builtinPlugins` accept lists of names. Unknown names
      fail during construction and list the valid names.
  </Tab>
  <Tab label="Rust">
    - `Effort` provides `Auto`, `Off`, `Minimal`, `Low`, `Medium`, `High`,
      `Xhigh`, and `Max`. A level the resolved provider rejects fails at
      construction.
    - Omitting `caching` enables it. An explicit request on a model instance or
      router is ignored with a warning.
    - `ContextManagerStrategy` provides `Auto`, `Agentic`, `Config`, `Instance`,
      and `Disabled`. Disabling it also disables context offloading.
    - `memory` accepts a boolean, `MemoryConfig`, or `MemoryManager`. An explicit
      SDK memory manager takes precedence.
    - `builtin_tools` accepts `BuiltinToolName` values or `BuiltinToolsConfig`.
      `builtin_plugins` accepts `BuiltinPluginName` values.
  </Tab>
</Tabs>

## Passthrough to the Agent

<Tabs>
  <Tab label="Python">
    Any keyword the factory does not name is forwarded to the underlying `Agent`
    constructor. An explicit value takes precedence over the corresponding harness
    default.
  </Tab>
  <Tab label="TypeScript">
    `HarnessAgentOptions` extends the SDK's `AgentConfig` minus fields the harness owns.
    An explicit value takes precedence over the corresponding harness default.
  </Tab>
  <Tab label="Rust">
    `HarnessAgentOptions` exposes the remaining typed `AgentConfig` fields directly.
    An explicit value takes precedence over the corresponding harness default.
  </Tab>
</Tabs>

For example, a supplied system prompt replaces `instructions`, and a supplied memory
manager replaces `memory`. See
[compose with the Strands Harness SDK](../../composing-with-sdk/).
